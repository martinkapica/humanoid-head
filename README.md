# Humanoid Head

A modular humanoid head project for exploring robotics, motion, perception and system integration through hands-on development.

> **Project Status: Planning**
>
> The project is currently in the preparation phase. Hardware components have been selected and ordered, but physical development and testing have not yet started.

## Initial Scope

The first development stage is planned around:

- Pan / Tilt head movement
- Camera-based perception
- Sensor integration
- Raspberry Pi based control
- ROS 2 as the future system framework

The project will be documented and expanded as development progresses.
